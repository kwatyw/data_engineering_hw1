Аналитический слой интернет-магазина:

Проект строит витрины по схеме "звезда" в Greenplum. Сервис loader копирует таблицы магазина из PostgreSQL в схему raw, а dbt строит из них три слоя:

- staging - по одной модели на таблицу источника
- intermediate - заказы с платежами, дерево категорий, покупки клиентов
- marts - факты fct_orders, fct_order_items и измерения dim_customers, dim_products, dim_dates

Витрины отвечают за: выручку по месяцам и категориям, долю покупателей по каналам, средний чек по городам, какие бренды чаще возвращают.
